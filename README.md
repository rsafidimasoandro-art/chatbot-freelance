# KIRANA AI — V1

Version professionnelle du chatbot KIRANA INGÉNIERIE.

## Contenu
- Interface responsive
- KIRANA AI
- Présentation des services
- Demande de devis
- Qualification des prospects
- Tableau local des prospects
- Export CSV
- Logo vectoriel intégré
- Aucun framework externe

## Mise en ligne
1. Remplacer l'ancien `index.html` par celui-ci dans le dépôt GitHub Pages.
2. Conserver le fichier à la racine du dépôt.
3. Attendre la reconstruction GitHub Pages.

## Important
Cette V1 stocke les prospects dans le navigateur (`localStorage`). Pour une vraie exploitation commerciale multi-utilisateur, il faudra connecter un backend/base de données et un canal d'envoi (email/WhatsApp).
